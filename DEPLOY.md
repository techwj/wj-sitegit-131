2. Configure your web server to serve static files
3. Visit your website

- `css/style.css`: Stylesheet
- `js/*.js`: JavaScript files
- `*.html`: Legal and other pages
- `sitemap.xml`, `robots.txt`, `ads.txt`: SEO files
